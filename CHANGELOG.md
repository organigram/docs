# Change Log

All notable changes to this project will be documented in this file.
See [Conventional Commits](https://conventionalcommits.org) for commit guidelines.

## [0.1.6](https://github.com/organigram/organigram/compare/v0.1.5...v0.1.6) (2026-07-20)

- Added generated reference pages for `@organigram/agent` and `@organigram/passkey-wallet`.
- Centralized TypeScript, React, and Solidity reference generation scripts for all published packages.
- Updated the JS, React, REST API, encryption, wallet connection, privacy, and terms documentation for the new auth and wallet surfaces.
- Refreshed pricing data generation and package exports used by the docs site.

## [0.1.5](https://github.com/organigram/organigram/compare/v0.1.4...v0.1.5) (2026-07-07)

- Added generated React reference documentation for the new agent components and refreshed JS, REST API, Solidity, network, and guide pages.
- Added AI usage pricing to the public pricing model and docs pricing table.
- Updated pricing generation to include local documented items alongside Stripe-backed prices.
- Refreshed certified, introduction, support, governance, and guide copy for the new product positioning.

## [0.1.4](https://github.com/organigram/organigram/compare/v0.1.3...v0.1.4) (2026-06-16)

- Split the docs into a standalone package with reusable navigation, sidebar, table-of-contents, pricing, link, and minimap components.
- Added new MDX content for introduction, guides, protocol, advanced, certified, and reference sections.
- Added generated pricing data plus REST API documentation generation support.
