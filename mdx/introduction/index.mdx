# 🌱 Start here

This documentation will walk you through the creation of incorruptible cryptographic organizations using Organigram.

{process.env.NEXT_PUBLIC_HOST_NAME} is an [open-source project](https://github.com/organigram) allowing any public or private organizations to prove mathematically that it follows a certain set of rules. Using AI and decentralized public networks to verify the integrity of an organization, it allows anyone to build and operate organizations that are more transparent, more resilient and more accountable than ever before.

The project is comprised of three parts:
- [The Organigram protocol](/docs/protocol), a universal language for operating cryptographic organizations easily and securely;
- [{process.env.NEXT_PUBLIC_COMPANY_URL}](/), a generative AI that allows anyone to create organizations from legal documentation automatically;
- [Organigram Certifed](/docs/advanced/certified), additional hosted services for giving legal value to cryptographic organizations.

Head to the next section for a codeless [quick start](/docs/introduction/get-started) to using the web platform, or jump to the [Protocol page](/docs/protocol) to get started with our open source stack.
