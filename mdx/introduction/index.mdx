# 🌱 Start here

This documentation will walk you through the creation of incorruptible organizations using Organigram.

Organigram is an [open source project](https://github.com/organigram) allowing any public or private organizations to prove mathematically that it follows a certain set of rules. Using AI and decentralized public networks to verify the integrity of an organization, it allows anyone to build and operate organizations that are more transparent, more resilient and more accountable than ever before.

The project is comprised of four parts:
- [Protocol](/docs/protocol): a universal language for operating cryptographic organizations easily and securely;
- [Agent](/docs/guides/draw-ai): an AI agent that allows anyone to create organizations from legal documentation automatically;
- [Passkey Wallet](https://wallet.organigram.ai): a simple standard for managing cryptographic identities online;
- [Certified program](/docs/certified): paid hosted services to give legal value to sensitive decisions taken on the platform.

Head to the next section for a codeless [quick start](/docs/introduction/get-started) to using the web platform, or jump to the [Protocol page](/docs/protocol) to get started with our open source stack.
