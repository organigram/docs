# React reference ⚛️

The official React documentation for the hooks, components, theme helpers, and utilities exposed by the Organigram.ai stack.

## @organigram/react

### Install

```bash
pnpm add @organigram/react
```

### Quick start

```tsx
import { Diagram, useOrganigramClient } from '@organigram/react'
```

### hook ++dnt++useOrganigramClient

Create an \{@link OrganigramClient\} tied to the provided viem clients.

The hook returns `null` until a public client is available.

```tsx
export const useOrganigramClient: (publicClient?: PublicClient | null, walletClient?: WalletClient | null) => OrganigramClient | null
```

**Parameters**

| Name | Description |
| --- | --- |
| `publicClient` | Read-only viem client used for chain queries. |
| `walletClient` | Optional wallet client used for write operations. |

## Utilities

### constant ++dnt++filterProposals

Filter hydrated proposals according to their workflow status.

```tsx
export const filterProposals: (
  filter: ProposalFilter,
  proposals: ProcedureProposal[]
) => ProcedureProposal[]
```

**Parameters**

| Name | Description |
| --- | --- |
| `filter` | Filter label selected by the UI. |
| `proposals` | Proposals to filter. |


### constant ++dnt++isUserInSourceOrgan

Check whether the current user belongs to the organ assigned to one procedure role.

```tsx
export const isUserInSourceOrgan: (
  roleType: ProcedureRoleTypeName,
  organs: OrganJson[],
  deployedProcedure?: ProcedureJson,
  userAddress?: string
) => boolean
```

**Parameters**

| Name | Description |
| --- | --- |
| `roleType` | Procedure role to inspect. |
| `organs` | Hydrated organs available in the current organigram. |
| `deployedProcedure` | Procedure whose role organ should be checked. |
| `userAddress` | Connected user address. |
