# Organigram React

Organigram React provides the React components and hooks of [Organigram.ai](https://organigram.ai): diagrams of organizations built on the [Organigram Protocol](https://organigram.ai/en/docs/protocol), the screens to propose and decide through procedures, and the chat panel of the workspace agent. It builds on `@organigram/js`, which reads and writes the contracts.

## Installation

```bash
pnpm add @organigram/react @organigram/js viem recoil react-flow-renderer @mui/material @mui/icons-material react-i18next
```

The components use [MUI](https://mui.com) for their styles and [Recoil](https://recoiljs.org) for the state they share, so wrap your application in a `RecoilRoot` and, to get the Organigram look, in a MUI `ThemeProvider` with `theme`. The theme expects its fonts at `/fonts/*.woff2`: copy `node_modules/@organigram/react/dist/fonts` to the public assets of your application.

## How it works

### Drawing an organigram

`Diagram` draws an organigram as an interactive graph: organs, procedures and assets are nodes, and the permissions they hold on each other are links. Users can move the nodes, and `onNodePositionsChange` lets you save their positions. `ClassicOrgChart` draws the same organigram as a classic tree, where an organ sits below the organ whose members decide on its membership.

Both take an organigram as plain JSON, from `organigram.toJson()`. Layers, defined by your application, let users show only part of a large organigram: `useLayers` filters the organigram for either view and remembers the active layers.

### Proposals and decisions

`procedures` holds the screens of each procedure type, by type name: `Component` describes a procedure, and `Proposal` shows a proposal with the actions the connected account may take, such as voting or blocking it.

### The workspace agent

`AgentPanel` is the chat panel of the workspace agent, including the preview of the changes the agent proposes, which the user confirms or cancels. They only render: your application sends the messages to its agent and stores the conversations. Every text can be replaced through the `labels` props, to translate them.

## Usage

```tsx
import { RecoilRoot } from 'recoil'
import { ThemeProvider, createTheme, type ThemeOptions } from '@mui/material/styles'
import { Diagram, theme, useOrganigramClient } from '@organigram/react'
import { Organigram, getTemplate } from '@organigram/js'
import { createPublicClient, http } from 'viem'
import { sepolia } from 'viem/chains'

const publicClient = createPublicClient({ chain: sepolia, transport: http() })

const OrganigramView = () => {
  const client = useOrganigramClient(publicClient, null, sepolia.id)
  const organigram = new Organigram(getTemplate('nonProfit', client?.chainId ?? String(sepolia.id)))

  return <Diagram organigram={organigram.toJson()} controls style={{ height: 600 }} />
}

export const App = () => (
  <RecoilRoot>
    <ThemeProvider theme={createTheme(theme as ThemeOptions)}>
      <OrganigramView />
    </ThemeProvider>
  </RecoilRoot>
)
```
