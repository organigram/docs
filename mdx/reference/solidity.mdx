# Solidity reference ⛓️

The official Solidity documentation for the contracts and types used in the Organigram.ai stack.

## @organigram/protocol

Solidity smart contracts for the [Organigram protocol](/docs/protocol).

### Install

```bash
pnpm add @organigram/protocol
```

Execute an external call that has been approved by a whitelist policy.

> The organ validates the call against the policy configured for `target + selector` before forwarding the call. Every configured constraint must pass.

```solidity

```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `target` | `address` | The external contract to call. |
| `value` | `uint256` | The amount of native token to forward with the call. |
| `data` | `bytes` | The encoded calldata forwarded to `target`. |
**Returns**

| Name | Type | Description |
| --- | --- | --- |
| `result` | `bytes` | The raw return data produced by the external call. |
