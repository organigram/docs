# 🔧 Reference

We released a set of [open-source libraries](https://github.com/organigram) to allow any developer to integrate the [Organigram Protocol](/docs/protocol) to their applications, and the web stack also exposes its own server-side API surface. These references include:
- [⛓ Solidity smart contracts](/docs/reference/solidity), the core of the Organigram Protocol, that can be deployed on any EVM-compatible blockchain;
- [⚙️ JavaScript/TypeScript](/docs/reference/js) API, that allows you to deploy and interact with contracts on any JS environment (backend or frontend);
- [⚛️ Hooks and components](/docs/reference/react) for easily integrating the Organigram Protocol into any React application;
- [🌐 Web API](/docs/reference/rest-api), the application endpoints used for auth, uploads, billing, and server-side actions.
- [🕸️ Supported Networks](/docs/reference/networks), the list of smart contract addresses of the Organigram Protocol deployed on each network;
- [📝 Legal terms](/docs/reference/terms), the legal terms that govern the use of this website.
- [👤 Privacy policy](/docs/reference/privacy), the privacy policy that explains how we handle user data and protect privacy when using Organigram.
