# Web API 🌐

The official reference for the API routes used by Organigram.ai. Unlike the package references, these endpoints document the application layer itself, including RPC-style JSON routes, uploads, authentication callbacks, webhooks, and server-side integrations.

## Conventions

- Most application mutations are sent as `POST` requests with a JSON body containing an `action` field.
- Upload and webhook routes disable the default Next.js body parser when they need raw bodies or `multipart/form-data`.
- Authentication varies by route: some endpoints are public, while others require a NextAuth session, a walletless token, or a provider-specific secret.

## Route summary

### Action routes

- [/api](/docs/reference/rest-api#route_api): Legacy RPC-style entrypoint that delegates an `action` payload to the concrete application route.
- [/api/account](/docs/reference/rest-api#route_apiaccount): Account, profile, and privacy operations for the current signed-in user.
- [/api/workspace](/docs/reference/rest-api#route_apiworkspace): Workspace reads and mutations, including membership and ownership changes.
- [/api/organigram](/docs/reference/rest-api#route_apiorganigram): Organigram, organ, procedure, entry, and asset mutations for authenticated users.
- [/api/organization](/docs/reference/rest-api#route_apiorganization): Organization lookups plus authenticated organization mutations.
- [/api/subscription](/docs/reference/rest-api#route_apisubscription): Subscription updates and invoice lookups for the current user or sponsor.

### Uploads and generated assets

- [/api/ipfs/\[...workspaceId\]](/docs/reference/rest-api#route_apiipfsworkspaceId): Uploads a workspace file to IPFS and tracks billable storage usage.
- [/api/certifiedProof/\[...workspaceId\]](/docs/reference/rest-api#route_apicertifiedProofworkspaceId): Generates, signs, stores, and bills a certified proof PDF for a workspace transaction.
- [/api/nlp/\[...workspaceId\]](/docs/reference/rest-api#route_apinlpworkspaceId): Builds an organigram draft from plain text or uploaded documents.

### Authentication, billing, and integrations

- [/api/auth/\[...nextauth\]](/docs/reference/rest-api#route_apiauthnextauth): NextAuth endpoint used for SIWE sign-in, session resolution, and auth callbacks.
- [/api/gasStation](/docs/reference/rest-api#route_apigasStation): Relays a transaction through the gas station after verifying signer and workspace access.


## Action routes

### ++dnt++/api

Legacy RPC-style entrypoint that delegates an `action` payload to the concrete application route.

| Field | Value |
| --- | --- |
| Methods | `POST` |
| Auth | Depends on the delegated action |
| Body | JSON payload with an `action` field |
| Notes | Prefer the concrete route once the target endpoint is known. |

Account, profile, and privacy operations for the current signed-in user.

| Field | Value |
| --- | --- |
| Methods | `POST` |
| Auth | Session required |
| Body | JSON payload with an `action` field |
| Notes | Also reachable through `/api` with the same `action` payload. |


**Actions**

| --- | --- | --- |

| `updatePrivacySettings` | Session required | Persists the current user privacy settings. |

## Uploads and generated assets

| Field | Value |
| --- | --- |

| Auth | Session with workspace access required |

**Operations**

| Operation | Trigger | Auth | Description |
| --- | --- | --- | --- |
| `upload` |   | Session with workspace access required | Uploads the first file from the multipart payload and returns its filename and CID. |

| Field | Value |
| --- | --- |
| Methods | `POST` |
| Auth | Session with workspace access required |
| Body | `application/json` with a `text` field or `multipart/form-data` with text fields and files |

**Operations**

| Operation | Trigger | Auth | Description |
| --- | --- | --- | --- |
| `infer organigram` |   | Session with workspace access required | Extracts usable text from the request and sends it to the inference service. |
