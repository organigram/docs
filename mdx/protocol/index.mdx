# Protocol 🧠

[Organigram.ai](/) follows a simple protocol to build organizations that can not be corrupted by a single individual.

It is comprised of three parts:
- [💎 Assets](/docs/protocol/assets) are resources that can be owned. They can be anything, from a physical object to a digital file. They are represented by [📦 ERC-20 tokens](https://eips.ethereum.org/EIPS/eip-20) and [📦 ERC-721 (NFT) tokens](https://eips.ethereum.org/EIPS/eip-721);
- [🫀 Organs](/docs/protocol/organs) are groups (of members or files) that can own [💎 Assets](/docs/protocol/assets).
- [🤖 Procedures](/docs/protocol/procedures) are rules that define how organs can be modified. These rules can be automated.

Combined, they can create transparent, intiuitive and incorruptible [💠 Organigrams](/docs/protocol/organigrams) to be managed easily by the community.
