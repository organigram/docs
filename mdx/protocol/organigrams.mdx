# Organigrams 💠

Now that we have all the elements of the protocol in place (Assets, Organs, Procedures) we can link them together and lay them out in an organigram 💠.

### Creating an Organigram

To create an organigram, click the "Add new" button in the [workspace sidebar](/workspace). Note that you need to have the permission to edit the workspace to create an organigram.

### Editing an Organigram

Once you have created an organigram, you can edit it by clicking on its name in the workspace sidebar.

It will open the organigram editor, where you can add, remove and connect elements.

#### Adding Elements

To add an element to the organigram, click the "Add" button in the bottom right corner of the editor.

#### Removing Elements

To remove an element from the organigram, open this element's menu and click "Remove".

#### Connecting Elements

To connect assets, organs or procedures, create a new procedure that use these elements as source and target. The link will be automatically created between these elements.

#### Export organigram

To export an organigram, click the expand button in the bottom right corner of the editor. It will display the advanced setting menu, where you can export your organigram in JSON, PNG or PDF format.

#### Advanced settings

The advanced menu will also let you switch direction (horizontal or vertical) and edit the organigram's name, description, and publicity.

You can decide to show or hide the links between a procedure and organs according to what they will modify. For example, if a procedure can modify the assets of an organ, you can decide to show or hide the link between the procedure and the organ in the organigram.

You can also delete the organigram from this menu.

### Deploying an Organigram

All elements of an organigram are usually first displayed as a draft. A draft asset, organ or procedure means that it has not been deployed to any blockchain network yet.

You can preview what your organigram will look like as a draft, but you will not be able to interact with it until it is deployed.

To deploy an organigram, we need to deploy all the assets, organs and procedures that it contains. This can be done automatically in one transaction by clicking the "Deploy" button.

The deployment process will allow you to preview its cost, and usually lasts under a minute.

You can either sign the and pay it directly with cryptocurrency, or [add payment information](/docs/advanced/transactions) to use a credit card or bank transfer.

After confirmationi of all the transactions, you can see that your organigram is now deployed. You can now interact with it in the [workspace](/workspace) or from the [explore page](/explore).
